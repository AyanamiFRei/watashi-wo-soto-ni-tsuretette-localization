[h1]English[/h1]

[h1]About the localization[/h1]

This is a complete unofficial English localization of [b]わたしをそとにつれてって[/b]. It translates the story, dialogue, choices, menus, system messages, input fields, and text baked into images.

The adaptation preserves the original buttons and their states, transitions, animations, timing, screen geometry, and overall pixel-art presentation. Character names, roles, and grammatical gender were checked against the context of the Japanese original.

[h1]Installing the English Patch[/h1]

[olist]
[*] Close the game completely.
[*] Extract the EN archive to a separate folder.
[*] Run [b]Install English patch.cmd[/b].
[*] The installer locates the game in your Steam libraries automatically. Press Enter to accept the detected folder, or enter another game-folder path.
[*] Wait for [b]app.asar[/b] rebuilding and verification to finish. This usually takes a few minutes.
[*] Launch the game from Steam after the installer reports successful verification.
[/olist]

If automatic detection fails, open the game folder through Steam: [b]Library → game properties → Installed Files → Browse[/b]. Select the root [b]わたしをそとにつれてって[/b] folder, not its [i]resources[/i] subfolder.

The download contains only modified files. It uses the Electron runtime already bundled with the game to rebuild the archive, so no additional software or internet connection is required. About 1.5 GB of temporary free space is required on the game drive.

[h1]Restoring the Japanese version[/h1]

The installer keeps a clean original as [b]resources\app.asar.original[/b] and creates an additional backup before every replacement. Run [b]Restore original.cmd[/b] to return to the Japanese version.

[h1]Updates and troubleshooting[/h1]

A Steam update may restore the original Japanese files. Let the update finish, then install the localization again.

If the installer cannot find a clean original [b]app.asar[/b], use Steam's [b]Verify integrity of game files[/b] option and try again. A new incompatible game build will require an updated localization package.

If you find untranslated text or a translation error, attach a screenshot and briefly identify the scene.
