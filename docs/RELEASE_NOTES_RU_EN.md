# Localization 2026-08-30

**by “Migdal Bavel” project.**

## Русский

Первый полный публичный релиз русской и английской локализации **わたしをそとにつれてって**.

В релиз входят два отдельных архива:

- `Watashi_wo_Soto_ni_Tsuretette_RU_2026-08-30.zip` — полный русификатор;
- `Watashi_wo_Soto_ni_Tsuretette_EN_2026-08-30.zip` — полный English Patch.

Переведены сценарий, интерфейс, кнопки, варианты выбора, поля ввода, телефон, финальная анкета и текст во вступительных анимациях. Сохранены оригинальный визуальный стиль, состояния кнопок, тайминги и переходы.

Установщик автоматически находит игру в библиотеках Steam, сохраняет чистый оригинал и проверяет собранную `app.asar` по SHA-256.

Проверено на Steam-сборке `24158896`, App ID `4879010`.

## English

The first complete public release of the Russian and English localizations for **わたしをそとにつれてって**.

This release contains two separate downloads:

- `Watashi_wo_Soto_ni_Tsuretette_RU_2026-08-30.zip` — complete Russian localization;
- `Watashi_wo_Soto_ni_Tsuretette_EN_2026-08-30.zip` — complete English localization.

The story, UI, buttons, choices, input fields, phone screens, final profile, and text inside intro animations are localized. The original visual style, button states, timing, and transitions are preserved.

The installer detects the game across Steam libraries automatically, keeps a clean original backup, and verifies the rebuilt `app.asar` with SHA-256.

Tested with Steam build `24158896`, App ID `4879010`.
